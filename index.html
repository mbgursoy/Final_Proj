Population Distribution and Left-Right Voting

Comparison of USA and France

Author

Mustafa Gursoy

Published

December 8, 2025

Introduction

This study aims to investigate the effects of different historical developments of ideological spectrum (left/right) on the relationship between urban-rural population distribution and the general election voting.

There are noted findings in the political science literature that rural areas tend to vote for right wing parties while more urban areas for left. However, different countries present different political histories, and in particular, the development of the breadth of left-right spectrum and the voters’ loyalty to their ideologies over time.

In this project, I compare the presidential elections of France-2022 and the USA-2020. I analyze how different the relationship between urban-rural population distribution and left-right voting behavior in France and in the USA.

I hypothesize that two reasons will effect differences in this relationship: first is the stronger tradition of left-wing politics in France; and the second is the wider spectrum of left-wing ideologies. The longer history of leftism can create a closer political affiliation between the rural population and the left-wing parties. The wider spectrum of political ideologies, on the other hand, can present various opportunities for political parties to establish rapport with the rural populations. This is because in a wider political spectrum, not only the number of parties are higher, but also the substantial issue positions adopted by parties can offer a higher variety in their combinations. In a biparty system, issue positions, such as A, B, C, D, are divided into two, while in a multiparty system the issue positions are not only divided into more sections, but also they are adopted by parties with overlaps such as Party-X can adopt A and B while Party-Y can adopt B and D. Since France has a multi-party system, multiple parties can address the interests of the rural voters in different ways, preventing the concentration of vote.

# 4.2) Restrict to 2020 results and build a GEOID

  dplyr::filter(.data[[year_col]] == 2020) |>
  dplyr::filter(!is.na(.data[[fips_col]])) |>
  dplyr::mutate(
    geoid = sprintf("%05s", as.integer(.data[[fips_col]]))
  )

# 4.3) Classify parties into Left / Right blocs
left_parties  <- c("DEMOCRAT", "DEMOCRATIC", "DEMOCRATIC-FARMER-LABOR")
right_parties <- c("REPUBLICAN")

us_lr <- us_elex_2020 |>
  dplyr::mutate(
    party_simpl = toupper(.data[[party_col]]),
    bloc_lr = dplyr::case_when(
      party_simpl %in% left_parties  ~ "Left",
      party_simpl %in% right_parties ~ "Right",
      TRUE                           ~ NA_character_
    )
  ) |>
  dplyr::group_by(geoid) |>
  dplyr::summarise(
    left_votes  = sum(.data[[candvote_col]][bloc_lr == "Left"],  na.rm = TRUE),
    right_votes = sum(.data[[candvote_col]][bloc_lr == "Right"], na.rm = TRUE),
    total_lr    = left_votes + right_votes,
    left_share  = dplyr::if_else(total_lr > 0, left_votes / total_lr, NA_real_),
    right_share = dplyr::if_else(total_lr > 0, right_votes / total_lr, NA_real_),
    lr_margin   = left_share - right_share,
    .groups     = "drop"
  )

# 4.4) Join Left/Right to the existing US mainland map
us_map2 <- us_map |>
  dplyr::left_join(us_lr, by = "geoid") |>
  dplyr::mutate(
    lr_winner = dplyr::case_when(
      lr_margin > 0  ~ "Left",
      lr_margin < 0  ~ "Right",
      TRUE           ~ NA_character_
    )
  )

  nom_col  = nom_cols,
  voix_col = voix_cols,
  stringsAsFactors = FALSE
)

cand_meta$candidate <- vapply(
  cand_meta$nom_col,
  function(col) {
    vals <- as.character(elex[[col]])
    vals[which(!is.na(vals))[1]]
  },
  character(1)
)

cand_meta$bloc_lr <- dplyr::case_when(
  cand_meta$candidate %in% left_tokens  ~ "Left",
  cand_meta$candidate %in% right_tokens ~ "Right",
  TRUE ~ NA_character_
)

dept_col <- nm_elex[grepl("code_du_departement", nm_elex, ignore.case = TRUE)][1]

elex <- elex |>
  dplyr::mutate(
    dplyr::across(
      dplyr::all_of(cand_meta$voix_col),
      ~ suppressWarnings(as.numeric(.x))
    )
  ) |>
  dplyr::mutate(
    dept = stringr::str_pad(
      as.character(.data[[dept_col]]),
      width = 2,
      side  = "left",
      pad   = "0"
    ),
    com  = stringr::str_pad(
      as.character(.data[[code_col[1]]]),
      width = 3,
      side  = "left",
      pad   = "0"
    ),
    code_insee = paste0(dept, com)
  )

left_voix_cols  <- cand_meta$voix_col[cand_meta$bloc_lr == "Left"]
right_voix_cols <- cand_meta$voix_col[cand_meta$bloc_lr == "Right"]

if (length(left_voix_cols) == 0 || length(right_voix_cols) == 0) {
  stop(
    "No left and/or right candidates detected in cand_meta.\n",
    "cand_meta:\n",
    paste(utils::capture.output(print(cand_meta)), collapse = "\n")
  )
}

elex_lr <- elex |>
  dplyr::mutate(
    left_votes = rowSums(
      dplyr::across(dplyr::all_of(left_voix_cols)),
      na.rm = TRUE
    ),
    right_votes = rowSums(
      dplyr::across(dplyr::all_of(right_voix_cols)),
      na.rm = TRUE
    )
  ) |>
  dplyr::group_by(code_insee) |>
  dplyr::summarise(
    left_votes  = sum(left_votes,  na.rm = TRUE),
    right_votes = sum(right_votes, na.rm = TRUE),
    total_lr    = left_votes + right_votes,
    left_share  = dplyr::if_else(total_lr > 0, left_votes / total_lr, NA_real_),
    right_share = dplyr::if_else(total_lr > 0, right_votes / total_lr, NA_real_),
    lr_margin   = left_share - right_share,
    .groups     = "drop"
  )
